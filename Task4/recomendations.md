## Описание вероятных проблем при миграции:

| Проблема                            | Вероятность | Влияние     | Приоритет |
|-------------------------------------|-------------|-------------|-----------|
| Потеря данных при миграции          | Высокая     | Критическое | P1        |
| Несогласованность данных            | Высокая     | Критическое | P1        |
| Отсутствие IAM                      | Высокая     | Критическое | P1        |
| Отказ интеграции лаборатории        | Средняя     | Высокое     | P2        |
| Перегрузка БД                       | Средняя     | Высокое     | P2        |
| Недостаток компетенций команды      | Средняя     | Высокое     | P2        |
| Ошибки в распределённых транзакциях | Средняя     | Среднее     | P3        |

## Рекомендации по уменьшению рисков:

### P1

* Ввести MDM для пациентов.
* Провести Data Quality аудит.
* Внедрить Keycloak.
* Провести инвентаризацию данных.
* Построить миграцию через Strangler Fig Pattern.

### P2

* Ввести API Gateway.
* Использовать асинхронные интеграции.
* Ввести централизованный мониторинг.
* Внедрить Kubernetes.
* Провести нагрузочное тестирование.

### P3

* Обучить сотрудников.
* Формализовать процессы.
* Ввести CI/CD.
